# ltxp for VS Code

Instant LaTeX preview in the browser, with exact two-way SyncTeX, through the `ltxp` language server. Install `ltxp` first; see https://github.com/SichangHe/latex_live_preview.

Open a `.tex` file: the preview opens in your browser. Click the preview to move the cursor to that exact character. Moving the cursor marks the same spot in the preview.

Settings: `ltxp.path` (default: `ltxp` on PATH, then `~/.local/bin/ltxp`) and `ltxp.cursorDelayMs`.
